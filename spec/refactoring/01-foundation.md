# Phase 1 — Foundation: Project Scaffold, Packaging & Configuration

## Objective

Establish the Python project structure, packaging tooling, and a type-safe configuration layer that mirrors the current layered dotenv/JSON config (`src/config/`) using **pydantic-settings**.

---

## Background

The current codebase is TypeScript. The configuration is built from:
- `src/config/schema.ts` — Zod schema for config shape
- `src/config/load.ts` — layered loader (env > user JSON > repo JSON > defaults)
- `src/config/merge.ts` — deep merge helpers
- `src/config.ts` — produces the flat `appConfig` export

The target replaces this with `pydantic-settings` `BaseSettings`, which natively supports env vars, dotenv files, and JSON/YAML source files with the same layering logic.

### 1.3 — Configuration (`src/agentloop/config.py`)

Define a single `Settings` class using `pydantic-settings` `BaseSettings`:

```
class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_nested_delimiter="__",
        extra="ignore",
    )
    # LLM
    mistral_api_key: SecretStr = ""
    llm_provider: str = "mistral"
    llm_model: str = "mistral-large-latest"
    llm_temperature: float = 0.0
    max_iterations: int = 20
    max_tokens_budget: int = 4000
    max_context_tokens: int = 8000
    llm_retry_max: int = 3
    llm_retry_base_delay_ms: int = 200

    # Tools
    tool_timeout_ms: int = 30000
    auto_approve_all: bool = False
    tool_allowlist: list[str] = []
    tool_blocklist: list[str] = []
    shell_command_blocklist: list[str] = []
    max_concurrent_tools: int = 5

    # Paths
    workspace_root: Path = Path.cwd()
    system_prompt_path: str = ""
    skills_dir: str = ""
    agent_profiles_dir: str = ""
    prompt_templates_dir: str = ""

    # Security
    max_file_size_bytes: int = 5_000_000
    max_shell_output_bytes: int = 500_000
    network_allowed_domains: list[str] = []

    # Search
    web_search_provider: Literal["duckduckgo", "tavily", "none"] = "duckduckgo"
    tavily_api_key: SecretStr = ""
    duckduckgo_max_results: int = 5

    # Web fetch
    web_domain_blocklist: list[str] = []
    web_domain_allowlist: list[str] = []
    web_allow_http: bool = False
    web_max_response_bytes: int = 2_000_000
    web_fetch_timeout_ms: int = 10000

    # Streaming
    streaming_enabled: bool = False

    # Observability / tracing
    tracing_enabled: bool = False
    trace_output_dir: str = "traces"
    tracing_cost_per_input_token_usd: float = 0.0
    tracing_cost_per_output_token_usd: float = 0.0

    # Logging
    log_level: str = "INFO"
    log_enabled: bool = True
    log_destination: Literal["stdout", "stderr"] = "stdout"
    log_file: str = ""

    # UI / misc
    ui_mode: Literal["cli", "tui"] = "cli"
    orchestrator: Literal["default"] = "default"
    plan_only: bool = False
    mcp_servers: list[dict] = []   # JSON array, parsed at runtime
```

Layering order (highest priority first):
1. CLI flag `--api-key` (applied as env override before `Settings()` is constructed)
2. Environment variables
3. `.env` file (root of project)
4. `docs/examples/user-config.json` (user overrides, optional)
5. `docs/examples/repo-config.json` (repo defaults, optional)
6. Pydantic field defaults

Expose a module-level `settings = Settings()` singleton (equivalent to `appConfig`).

### 1.4 — Logger (`src/agentloop/logger.py`)

- Use `structlog` configured to emit JSON to stdout/stderr.
- Respect `settings.log_level`, `settings.log_destination`.
- Expose a `get_logger(name)` factory (equivalent to `logger.ts`).

### 1.5 — Error Types (`src/agentloop/errors.py`)

Define Python exception classes mirroring `src/errors.ts`:

| TypeScript | Python |
|---|---|
| `LLMAPIError` | `class LLMAPIError(RuntimeError)` |
| `ToolExecutionError` | `class ToolExecutionError(RuntimeError)` |
| `ToolBlockedError` | `class ToolBlockedError(RuntimeError)` |

### 1.6 — .env.example

Mirror all settings from §1.3 as commented-out env vars with their defaults. This replaces `.env.example` (TypeScript) with a Python-compatible equivalent.
